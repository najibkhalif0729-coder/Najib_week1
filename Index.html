Computers do not find each other by name; they find each other by number. Before anything else, your browser asks a directory service called DNS to turn wikipedia.org into an address like 198.35.26.96. It works like looking up a contact name to get a phone number. Your browser sends a request. It travels to that address and says, in effect, send me the page at this path. The server sends a response. The response has two parts: a status code saying how it went, and a body containing the actual content. You have met status codes before. 200 means fine, here it is. 404 means no such page. 500 means the server broke.
